# Iris Flower Classification — Project Report

## 1. Objective
The objective is to classify Iris flowers into Setosa, Versicolor, and Virginica using sepal and petal measurements.

## 2. Dataset
The project uses the classic Iris dataset available through scikit-learn. It contains 150 samples, four numerical features, and three classes.

## 3. Preprocessing
The data is split into 80% training and 20% testing data. StandardScaler is used to standardize the features.

## 4. Model
Logistic Regression is trained using the four flower measurements.

## 5. Evaluation
The model is evaluated using accuracy, precision, recall, F1-score, classification report, and a confusion matrix.

## 6. Prediction
The trained model is used to classify a new Iris flower from its measurements.

## 7. Conclusion
This project demonstrates a complete machine-learning classification workflow from dataset loading through model evaluation and prediction.
