# Iris Flower Classification

A complete beginner-friendly machine learning classification project designed for Google Colab.

## Objective
Classify Iris flowers into Setosa, Versicolor, and Virginica using four measurements:
- Sepal length
- Sepal width
- Petal length
- Petal width

## Algorithm
Logistic Regression

## Dataset
The classic Iris dataset built into scikit-learn. No external CSV download is required.

## How to run in Google Colab
1. Open Google Colab.
2. Upload `Iris_Flower_Classification.ipynb`.
3. Open the notebook.
4. Select **Runtime → Run all**.
5. Wait for all cells to finish.
6. Review the graphs, metrics, confusion matrix, and prediction.
